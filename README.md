# Mobile Onboarding Flow UI

A clean and modern mobile onboarding flow designed to create a smooth first-time user experience. This concept focuses on simplicity, user engagement, and a visually pleasing interface using soft purple tones and minimal illustrations.

## Screens Included

### 1. Welcome Screen
Introduces users to the app with a friendly illustration and welcoming message.

### 2. Planning Screen
Highlights task organization, goal setting, and productivity features.

### 3. Progress Screen
Encourages users to track achievements and stay motivated.

## Design Highlights

- Minimal and modern UI
- Soft pastel purple color palette
- User-friendly onboarding experience
- Clean typography and spacing
- Mobile-first responsive layout
- Smooth visual flow between screens

## Tools Used

- Figma / Canva
- UI/UX Design Principles
- Mobile App Design Concepts

This project was created as a UI/UX practice concept for portfolio presentation, internship applications, and design inspiration.
